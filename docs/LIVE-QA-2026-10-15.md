## `{% stylesheet %}` is NOT subsetted per page (DECISIONS 3 check)
- `compiled_assets/styles.css` is the same URL (v=126670130420813578911792085873) and size (41,471 B) on home and product, and contains CSS of sections that are not on the page (`.av-welcome` on the product page).
- Consequence: every section's `{% stylesheet %}` ships on every page; with 46 more sections this grows to a few hundred KB.
- Action (after the section-library workflow): move each section's `{% stylesheet %}` into `assets/anvil-<slug>.css` loaded with `stylesheet_tag` from the section; keep only tiny theme-block CSS in the bundle (or extract too); update CONVENTIONS §3, chassis-lint (no `{% stylesheet %}` in sections), DECISIONS 3.
