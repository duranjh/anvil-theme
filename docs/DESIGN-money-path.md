# Anvil — Money-path design

_Design document, 2026-10-14. Part of the Anvil theme (MIT). Written from Shopify's public documentation only._

Naming reconciliation with Appendix A: the product section file is `sections/main-product.liquid` (template-bound `main-*` convention), its blocks render from `snippets/anvil-pb-<block>.liquid`; `anvil-featured-product` is the addable twin. The free-shipping threshold lives on the drawer's `free_ship_bar` block, not in theme settings.

Conventions: files `sections/anvil-*.liquid`, `snippets/anvil-*.liquid`, `assets/anvil-*.css|js`; custom elements `<anvil-*>`; our own setting ids; every merchant-facing string in `locales/en.default*.json`. No bundler, no icon font, no remote assets (so no kill switch is even possible).

## A. `sections/anvil-main-product.liquid`
- **Layout:** two columns on desktop (`gallery_position: left|right`, `gallery_width` 40–60%), stacked on mobile, gallery first. One `{% form 'product', product, id: form_id %}` wraps only the hidden `id` input and the `buy_buttons` block; every other posting block (quantity, custom field, sticky bar) uses `form="{{ form_id }}"` so block order is free.
- **Gallery** (section settings; `snippets/anvil-gallery.liquid`, `<anvil-gallery>`): `gallery_thumbs_desktop: left|bottom|hidden|stacked`, `gallery_thumbs_mobile: hidden|bottom`, `gallery_pager_mobile: dots_under|dots_overlay|numeric|hidden`, `gallery_mobile_peek` (0–40 px), `gallery_zoom: none|hover|lightbox`, `gallery_variant_image_first` (on), `gallery_hide_other_variant_media` (replaces the kit's CSS hack), video autoplay/loop/muted/controls. Mobile = CSS scroll-snap list + IntersectionObserver for active dot/counter; desktop thumbs are `<button aria-controls>`. Slides carry `data-media-id` and `data-variant-ids` (media.id → variants whose `featured_media` is that media). Video via `video_tag`/`external_video_tag` (poster, iframe on tap). Lightbox is a native `<dialog>`. One media → no pager; none → placeholder SVG.
- **Blocks:** all 37 are *local* section blocks (a section can't mix `@theme` and local blocks; the kit writes flat `product.json` block lists). One dispatcher snippet `snippets/anvil-product-block.liquid` `case`s on `block.type` and renders the feature snippet with `product, block, form_id, current_variant`. `anvil-featured-product` renders the same dispatcher (schema omits `sticky_atc`, `quantity_gifts`). Both schemas are generated from `docs/product-blocks.schema.json` by `scripts/sync-block-schemas.py`; CI fails on drift.
- **Order constraints:** `sticky_atc` (limit 1) and `offer_card` blocks (limit 6) are collected on a first pass and rendered out of order (bar after the section root, cards inside the picker). `@app` listed. Typical page: 15–25 instances + up to 6 cards, under the 50 cap.
- **Shared snippets:** `anvil-icon`, `anvil-price`, `anvil-payment-badges`, `anvil-text-icon`, `anvil-icons-text`, `anvil-ship-dates`, `anvil-product-card-mini`, `anvil-rating-stars`, `anvil-countdown`.

## B. Variant picker (`variant_picker` block)
- `picker_style: dropdown|pills|cards`, `picker_hide_sold_out`, `size_chart_option_name`.
- **Dropdowns:** one `<select>` per `product.options_with_values`; sold-out suffix from `product_option_value.available`. **Pills/swatches:** `<fieldset>` of radios; `value.swatch` color/image when `pills_use_swatches`; fallback theme setting `swatch_fallback_colors` (textarea `Name:#hex`); unmatched names stay text pills.
- **Offer cards** (the kit's ladder): data from `offer_card` blocks: `card_variant_position` (defaults to block order), `card_label`, `card_caption`, `card_badge`, `card_badge_backed_by_sales` (badge renders only when ticked; `info`: "Only tick if sales data supports this badge"), `card_benefit`, `card_show_image`. Picker-level: `offer_cards_option` (which option drives cards), `offer_cards_preselect` (0 = first available, 1–6 = card N), `offer_cards_savings: amount|percent|both|none`, `offer_cards_image_source: variant|none`. No blocks → cards auto-generate from option values. Each card is a radio for one option value; price from `product_option_value.variant`, so 2+ options work (other options render as pills under the cards). Strike-through and "You save" = `compare_at_price - price` only when compare_at > price; **no manual savings field**. Preselect is server-side (when `product.selected_variant == nil`), no URL change; `?variant=` always wins (ad links and the kit work without a post-load script).
- **Variant-change flow** (`<anvil-variant-picker>`, `assets/anvil-product.js`): `<script type="application/json" data-anvil-variants>` = `product.variants | json` + our map `{id: {inventory_quantity, inventory_management, inventory_policy, media_ids}}`; `window.Anvil.moneyFormat = shop.money_format`. On change: resolve variant → set `id` input → update price/compare/savings, SKU, availability, inventory text, gallery, sticky bar → `history.replaceState` with `?variant=` preserving UTM/fbclid → one Section Rendering fetch `?section_id=…&variant=ID` swaps only `[data-anvil-server-truth]` nodes (inventory, market-priced money, pickup); if it fails the instant client values stand. Verify in dev whether `variant | json` includes `featured_media`; else use our `media_ids`. Unavailable combination → "Unavailable", card `aria-disabled`; JS off → native selects/radios submit normally.

## C. Buy buttons + sticky bar
- `buy_buttons`: `atc_label`, `atc_sold_out_label`, `show_dynamic_checkout` (default **off**; `info`: express buttons skip the drawer so upsells/gifts are never seen), `show_secure_line`. `{{ form | payment_button }}` inside the form.
- `sticky_atc` (limit 1, `<anvil-sticky-bar>`): `sticky_atc_mobile` (on), `sticky_atc_desktop` (off), `sticky_atc_show_image|price|quantity`, `sticky_atc_label`. IntersectionObserver on the main button; `hidden` by default so JS-off never shows it; button has `form="{{ form_id }}"`; quantity mirror has no `name`; bottom-fixed with `env(safe-area-inset-bottom)` and matching page padding. No express buttons in the bar.

## D. Quantity, tiers, gifts on quantity
- `quantity`: `quantity_style: stepper|tiers`, min/max/step honour `variant.quantity_rule`. **Tiers:** `quantity_tier` blocks (limit 5): `tier_qty`, `tier_label`, `tier_badge`, `tier_discount_percent`, `tier_discount_title`. A tier card sets the quantity input; displayed per-unit price computed from `tier_discount_percent` and labelled "with [title] applied at checkout". `info`: create an automatic "Amount off products" discount with minimum quantity N (25 max) and copy its percentage here; the theme shows it, Shopify grants it. After add-to-cart the drawer compares `line_level_discount_allocations` to the promise; in `request.design_mode` a mismatch shows a red merchant note. Documented honest alternative: pack variants via offer cards or Shopify Bundles multipacks.
- `quantity_gifts`: `gift_product`, `gift_variant_position`, `gift_min_qty`, `gift_label`. **Gift engine** (`assets/anvil-gifts.js`, shared with the drawer): after every `anvil:cart:updated`, count the trigger product's non-gift quantity; ≥ N and no line with property `_anvil_gift = "<trigger_id>:<N>"` → `POST /cart/add.js {items:[{id, quantity:1, properties:{_anvil_gift}}], sections}`; < N and line exists → `/cart/change.js {id: key, quantity: 0}`. Price truth from a Buy X Get Y automatic discount (Shopify never auto-adds the get item). Drawer prints "FREE" only when `line.final_line_price == 0`. Guards: gift lines have no stepper, clamped to 1; shopper removal sets `sessionStorage anvil_gift_dismissed:<key>`; 422 swallowed; events with `source: 'gift'` ignored (no loops).

## E. Bundle offer and upsells
- `bundle_offer`: `bundle_heading`, `bundle_products` (product_list, limit 3), `bundle_include_current`, `bundle_preselect_all`, `bundle_discount_note`. Rows: checkbox, variant select, price, image. Total = sum of selected variant prices (Liquid initial, JS live); if a set discount exists the note is shown and "Discount applied at checkout"; never a fabricated bundle price. One `/cart/add.js` with `items[]` + `sections`; partial 422 fails whole request → show `description`.
- `upsells` (product + drawer): `upsell_source: manual|recommendations`, `upsell_products` (limit 4), `upsell_intent: related|complementary`, `upsell_limit` 1–4, `upsell_hide_in_cart`. Recommendations via `routes.product_recommendations_url?section_id=anvil-upsell-row&product_id=…&intent=…&limit=…` (verify `section_id` support; fallback JSON + `<template>`). Complementary needs Search & Discovery configured; empty → renders nothing.

## G. Cart drawer (`sections/anvil-cart-drawer.liquid`)
- Rendered once from `theme.liquid` with `{% section 'anvil-cart-drawer' %}` (static ID `anvil-cart-drawer`). `<anvil-cart-drawer>` wraps a native `<dialog>` (`showModal()` = focus trap, Esc, inert background). Opened by the header cart link (`<a href="{{ routes.cart_url }}">` upgraded by JS; JS-off → `/cart`) and after `anvil:cart:updated` with `source: 'add'` when `cart_open_on_add`. Body is `<form action="{{ routes.cart_url }}" method="post">` so JS-off works (`updates[]` steppers, `/cart/change?id=key&quantity=0` remove links, `<button name="checkout">`).
- Re-render: every mutation requests `sections=anvil-cart-drawer`; header bubble updates from JSON `item_count` (optional static `anvil-cart-icon` section supported). Replace `[data-anvil-drawer-body]` / `[data-anvil-drawer-footer]` children; restore focus by `data-anvil-focus-key`.
- Blocks (16, each with `place_in_footer`): `items` (limit 1; stepper, remove, per-line allocations, 422 → toast with Shopify's `description` + rollback), `subtotals` (`items_subtotal_price`, savings line from allocations, optional `show_compare_savings`), `checkout` (limit 1; `secure_text`, `show_payment_icons`), `free_ship_bar`, `checkpoints_bar`, `countdown`, `upsells`, `gift_threshold`, `text_icon`, `image`, `icons_text`, `payment_badges`, `discount_field`, `note`, `policies_check`, `custom_liquid`. `@app` is not supported in static sections (review apps live on the product page).
- **Free shipping bar:** `ship_bar_threshold` (shop currency), `ship_bar_market_thresholds` textarea `market-handle:amount` keyed by `localization.market.handle`, `ship_bar_text_before` with `{{ remaining }}`, `ship_bar_text_after`, `ship_bar_exclude_gift`. Compares against `cart.total_price` (verify against the rate condition on a test order). Foreign currency without a market line → bar hides. `info`: the bar does not create free shipping.
- **Checkpoints bar:** 3 slots `cp_N_amount|label|icon`; visual only.
- **Countdown:** `countdown_ends_at` (ISO), `countdown_timezone`, `countdown_label`, `countdown_expired: hide|text`. Liquid renders expired state server-side; JS ticks. **No evergreen/per-visitor mode**; `info` says why.
- **Gift at threshold:** `gift_product`, `gift_variant_position`, `gift_threshold_amount`, `gift_label`; same engine as B.D with trigger = `cart.total_price` excluding gift lines; pair with Buy X Get Y.
- **Discount field:** `/cart/update.js {discount}`; applied codes from `cart.discount_applications`; removing one re-sends the rest; `''` clears.
- **Note:** `update.js {note}` on blur, debounced. **Policies checkbox:** `policy_text` richtext; unchecked disables checkout (`aria-describedby`); `required` blocks JS-off submit; state in `attributes[anvil_terms_accepted]`.
- Drawer settings: `drawer_width` (320–560 px desktop; full width < 768 px), `drawer_color_scheme`, `cart_open_on_add`, `drawer_preview_open` (only in `request.design_mode`).

## H. Events and state (`assets/anvil-core.js`)
`Anvil.cart.add(items, opts)`, `.change(key, qty)`, `.update(payload)` wrap fetch to `routes.cart_*_url + '.js'`, always send `sections`, dispatch `anvil:cart:updated` `{cart, sections, source}`. Subscribers: header bubble, drawer, sticky bar, upsells, gift engine. Optimistic UI only for the stepper number (`aria-busy`); totals from the server. Concurrency: 300 ms debounce per line, `AbortController` per line key, monotonic sequence number drops stale responses. Errors: non-2xx → `description` toast, restore last good cart. `Shopify.designMode` + `shopify:section:load` re-init in the editor.

## J. Test matrix
320/375/390 px + desktop (pager modes, card labels one line at 320, sticky bar not covering content, drawer full width); 1-tier and 3-tier products (auto-cards vs blocks, preselect 2, `?variant=` overrides, strike-through only where compare_at > price, "You save" arithmetic); sold-out variant; 2 options (cards + pills, prices per card); cart 0/below/at/above threshold (bar text/width, hidden in foreign currency without market line, gift add once/remove below, "FREE" only at 0, dismissed stays dismissed); discount apply/fail/remove one of two; 422 on stepper (rollback, focus kept); JS disabled (form posts to `/cart/add`, cart link → `/cart`, drawer form posts, `required` blocks checkout); editor (`shopify:section:load`, `drawer_preview_open` design-mode only, placeholder content everywhere); Lighthouse mobile perf ≥ 80 / a11y ≥ 95.

## K. Honest-marketing refusals baked in
No evergreen/per-visitor timers; no stock counts for untracked inventory or typed numbers; no manual "you save" or bundle total; no star number without a metafield or source URL; "FREE" only when Shopify priced the line at zero; "most popular" badge only when the sales-backed box is ticked; no granted or simulated discounts (display only, with a design-mode warning when promise and allocation disagree); no third-party logos. Each refusal has a plain-words `info` sentence.
