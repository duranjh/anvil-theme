# Anvil — Reconciliation of the three designs

_Design document, 2026-10-14. Part of the Anvil theme (MIT). Written from Shopify's public documentation only._

1. **From scratch, not Dawn.** Dawn/Skeleton/Horizon licences are Shopify-only with Theme Store distribution; Anvil is fully original code under MIT so the zip and repo are clean.
2. **Naming.** Classes `.av-*`, CSS variables `--av-*` (Appendix A); Appendix C's `.anvil-*`/`--a-*` examples read as `.av-*`/`--av-*`. Base stylesheet is `assets/anvil-base.css` (C's `anvil-core.css`). Template-bound sections are `main-*` (C's `anvil-main-*` reads as `main-*`); everything else we author is `anvil-`/`_anvil-`.
3. **CSS placement.** Shared component CSS (slider, marquee, product card, drawer, gallery, header) lives in `assets/anvil-<component>.css` loaded by `stylesheet_tag` from the sections that use it; section-only static CSS goes in that section's `{% stylesheet %}` (≤ 6 KB, no Liquid). **Wave-0 check:** confirm the bundled stylesheet is subsetted per page; if not, section CSS moves to `assets/anvil-<slug>.css`. Per-instance values (padding, widths) via `{% style %}` scoped by `#shopify-section-{{ section.id }}`.
4. **Cart drawer** is a static section rendered from `theme.liquid` (`{% section 'anvil-cart-drawer' %}`), not an `aside` group (would let merchants drop arbitrary sections into the drawer). **Wave-0 check:** static-section blocks editable in the editor; fallback `block_list`-style settings.
5. **Overlay group.** `sections/overlay-group.json` (`type: custom.overlay`, rendered after the footer group) holds floating widgets: scroll-to-top, audio player, promo popup. Three groups used of 20.
6. **Blocks.** Product section and data-row sections use local blocks; container/content sections use `@theme` primitives; private `_anvil-*` blocks only where a row contains primitives. Product block schemas for `main-product` and `anvil-featured-product` are generated from `docs/product-blocks.schema.json`.
7. **Icons.** One `snippets/anvil-icon.liquid` with ~120 Lucide icons (ISC, credited in `NOTICE`); merchants can upload a custom image where an icon setting exists. No icon font.
8. **Screenshots** use `?view=anvil-scratch-<slot>` on any existing page of the dev theme; no store pages are created.
9. **Free-shipping threshold** lives on the drawer's `free_ship_bar` block (per market textarea), not in theme settings.
10. **Locales** English-only in v1.0; marketing copy in settings; a11y strings under `anvil.*`.
11. **Honest defaults** (hard line 6) are implemented as Appendix B.K and the `info` texts in every spec card; Shopify's Theme Store honesty rule is quoted in `docs/HONEST.md`.

_Wave-0 integration (2026-10-14), reconciling the five chassis clusters:_

12. **Dialog element name.** The native-`<dialog>` wrapper is `<anvil-dialog>` (CONVENTIONS §6); ARCHITECTURE §4's `<anvil-modal>` reads as `<anvil-dialog>`.
13. **Focus helpers.** `anvil-dom.js` exports `confineFocus(container, {initial, restore}) → release()`, `releaseFocus(container, {restore})` and `focusables(root)`. The reference-theme names in `docs/FORBIDDEN.md` stay banned; CONVENTIONS §7 was amended to the shipped names.
14. **Route and string keys.** `window.Anvil.routes` uses camelCase keys (`cartAdd`, `cartChange`, …; `anvil-cart-api.js` also accepts the Liquid names) and `window.Anvil.strings` uses camelCase keys with `[var]` placeholders. New strings are added in `layout/theme.liquid` from `anvil.*` locale keys; modules keep an English fallback.
15. **Theme Check config.** `.theme-check.yml` ignore globs are anchored (`/dev/**`, `/docs/**`, `/scripts/**`); the unanchored `dev/**` matched a checkout under `~/dev/` and made the gate inspect 0 files. `scripts/gate.sh` still refuses a 0-files run.
16. **Asset size rule.** Shopify CLI 4.9.3's `AssetSizeJavaScript` measures the raw bytes of each referenced asset (verified: 18,208 B raw / 5 KB gz failed at 15,000). With `thresholdInBytes: 15000` every module loaded by a Liquid file must stay under 15,000 raw bytes; the documents' gzip budgets remain the design intent. Revisit the threshold before wave 1 (product JS).
17. **Drawer controls live in theme settings.** `drawer_width`, `cart_open_on_add` and `cart_show_note` are theme settings (`--av-drawer-width`, `Anvil.settings.openCartOnAdd`); the drawer schema keeps only `heading`, `color_scheme`, `drawer_preview_open`. DESIGN-money-path §G's per-drawer copies are dropped to avoid two sources of truth.
18. **Shared component CSS** is loaded by the section that renders the element (`stylesheet_tag`, deduped by URL): `anvil-slider.css` with `<anvil-slider>`, `anvil-card.css`/`anvil-media.css` with the card, price, stars and media snippets, `anvil-dialog.css` wherever `.av-dialog`/`.av-drawer__*` classes are used. The header styles its own menu drawer and does not load `anvil-dialog.css`.
19. **Locale keys during waves.** Locale files are read-only for section agents; they list needed `anvil.<area>.*` keys in their notes and the integrator adds them at wave end. CONVENTIONS §1 was amended accordingly.

_Fix pass after the wave-0 review (2026-10-14). Entries 20–27 are the owner's answers to STATUS §5 (A–H); 28–40 are decisions the fixer took while applying the review findings._

20. **Asset size budgets (owner decision A).** `.theme-check.yml` sets `AssetSizeJavaScript` and `AssetSizeCSS` to `thresholdInBytes: 40000` (the CLI measures raw bytes, entry 16). The gzip budgets are enforced per file by `scripts/check-limits.sh`, which fails with the file and its size: core modules (`anvil-core`, `-events`, `-cart-api`, `-sections`, `-dom`) together ≤ 15,360 B; `anvil-slider.js` ≤ 5,120; `anvil-marquee.js` ≤ 1,536; every other `assets/anvil-*.js` ≤ 4,096; `anvil-base.css` ≤ 20,480; every other `assets/anvil-*.css` ≤ 8,192. This replaces ARCHITECTURE §10's `AssetSizeCSS (30000)` and entry 16's 15,000-byte JS ceiling.
21. **Collapsible height animation stays (owner decision B).** `<anvil-collapsible>` animates the height of a disclosure body with the Web Animations API, only when motion is allowed and `html[data-animations]` is on. Disclosure widgets are the one exception to "only transform/opacity animate"; CONVENTIONS §8 says so.
22. **Reduced chassis (owner decision C).** Group-only and overlay sections (`anvil-header`, `anvil-announcement-bar`, `anvil-footer`; later `anvil-scroll-top`, `anvil-audio`, `anvil-popup`) carry only `color_scheme`, `pad_top`, `pad_bottom`, `pad_mobile`, `show_on`. Their schemas and Liquid were updated (no section head), `anvil-section-attrs` falls back to the chassis defaults for missing ids, CONVENTIONS §4 has a "Reduced chassis" paragraph and `scripts/chassis-lint.py` enforces the exact ids and types (and rejects the full-chassis ids) for sections whose `enabled_on` is groups-only, `custom.overlay` included.
23. **Storefront strings in locale files (owner decision D).** Every plain English shopper-facing string in `sections/main-*.liquid`, the customer sections, `templates/gift_card.liquid`, the header/footer localisation forms, the contact form and the product card placeholders now uses `| t` with keys under `anvil.<area>.*` (`anvil.collection`, `anvil.facets`, `anvil.customer`, `anvil.gift_card`, `anvil.password`, `anvil.article`, `anvil.blog`, `anvil.list_collections`, `anvil.not_found`, `anvil.localization`, `anvil.footer`, `anvil.contact_form`, `anvil.header`, `anvil.announcement`). Dates use `time_tag: format: 'anvil_date'` / `date: format: 'anvil_date'` from `date_formats.anvil_date`. `layout/password.liquid` had none left. Theme Check `TranslationKeyExists` passes. Social network names stay as plain text (proper nouns).
24. **Lucide `smile` dropped (owner decision E).** It does not exist upstream; no list or document names it and no alias was added. 143 icons ship.
25. **Labels in lists are not headings (owner decision F).** `anvil-icon-bar` item labels stay `<span>` inside `<li>`. CONVENTIONS §3 now reads "content headings inside blocks are `<h3>`; short labels in lists are not headings". Empty-editor notes use the shared `anvil.editor.empty_section` ("Add blocks to show content here."); `anvil.icon_bar.empty_editor_note` and `anvil.faq.empty_editor_note` were removed.
26. **FAQ structured data on the FAQ page (owner decision G).** `templates/page.faq.json` = `main-page` → `anvil-faq` (anchor `shipping`) → `anvil-faq` (anchor `product`), nothing else. **Both ship with `json_ld: false`** (revised 2026-10-14): the preset questions are examples, and an unedited store must not publish example Q&As as FAQPage structured data. The setting's info tells the merchant to turn it on for one FAQ section per page once the answers are real. The questions read as examples ("Example question — …"). The contact, track-order, landing and home templates also gained example FAQ sections, all with `json_ld: false`.
27. **Derived documents generated (owner decision H).** `python3 scripts/spec-cards.py` wrote `docs/spec/<slug>.md` for every SPEC §4.2 row and `python3 scripts/agent-prompt.py anvil-ticker --write-chassis-api docs/CHASSIS-API.md` wrote the chassis API from the snippet and block `{% doc %}` headers (every theme block now has one).
28. **Core modules load from versioned URLs.** `anvil-core.js` loads `anvil-events`, `-cart-api`, `-sections` and `-dom` with `import()` from `window.Anvil.modules` (the `asset_url` values, written by both layouts) and the layouts preload the same URLs with `<link rel="modulepreload">`. Relative static imports resolved to unversioned URLs, which could not reuse a preload and could mix a new core with a cached older module after a theme update. The three modules no longer import `anvil-events.js`; they reach the bus through `window.Anvil.events` (or a plain document event).
29. **Media, price and stars styles live in `anvil-base.css`.** Theme blocks can render `anvil-media`, `anvil-price` and `anvil-stars` anywhere without loading another file, so these rules (about 3 KB raw) moved into the base stylesheet and `assets/anvil-media.css` was deleted. `anvil-card.css` now holds only the card. Amends entry 18.
30. **Enhancement is keyed on `:defined`.** A control that only works with a module (steppers, live discount field) is `.av-enhanced-only`, and the fallback it replaces (Update / Apply buttons) is `.av-fallback-only`, inside a custom element with class `.av-enhance`. The country/language forms keep a visible Update button and never auto-submit (WCAG 3.2.2). New modules: `anvil-cart.js` (`<anvil-cart-form>`), `anvil-cart-drawer.js` (replaces the inline `{% javascript %}` element), `anvil-facets.js`, `anvil-predictive-search.js` (+ `sections/anvil-predictive-search.liquid`, SRA only), `anvil-code.js`.
31. **Naming clean-up.** State classes are `.av-is-*`; `anvil-section-attrs` emits `av-s-<type>` instead of the bare type; the group theme block is `.av-group-block`, the contact form `.av-contact-form`, the announcement bar `.av-announcement-bar`; hooks are `data-anvil-*` (`data-anvil-media-id`, `data-anvil-default`, `data-anvil-page`) and marquee clones are `.av-marquee__clone`. Schema names stay sentence case and CONVENTIONS §1 now says so (matching the Shopify editor).
32. **Cart drawer re-render contract.** The swap root is the inner `.av-cart-drawer__frame` (`data-anvil-section="anvil-cart-drawer"`), so a re-render never removes the open `<dialog>`; `<anvil-cart-drawer>` releases its scroll lock when it is disconnected while open, closes on a backdrop click, and opens after an add by listening for `anvil:cart:updated` on `document` (the old inline element ran before `window.Anvil.events` existed). The header bubble swaps through a slot (`snippets/anvil-cart-bubble.liquid`) shared by the header and `sections/anvil-cart-bubble.liquid`, so bubbles never nest. `anvil-core.js` swaps every section an `anvil:cart:updated` event carries.
33. **Countdowns count to one instant.** Without a time zone the block writes `data-anvil-end` (epoch seconds computed by Liquid in the store's time zone) and the info text says "your store's time zone". Only values starting with a full `YYYY-MM-DD` count as a date, so a bare time can no longer become a timer that restarts every day. The script un-hides a block the server hid while time remains.
34. **Header CSS is an asset.** The header grew a mega menu, menu positions, a tiles drawer, a no-JS drop-down menu and predictive results; its CSS (10 KB raw, 2.3 KB gz) is `assets/anvil-header.css`, loaded with `stylesheet_tag` by the header, because a section `{% stylesheet %}` is capped at 6 KB. Extends entry 18.
35. **Icon lookup is split by first letter.** `snippets/anvil-icon.liquid` dispatches to `anvil-icon-a-c`, `-d-l`, `-m-r`, `-s-z`, each a short `case`/`when`; the capture-and-split table re-parsed 27 KB per icon and one 143-branch `case` exceeded Theme Check's `LiquidComplexity`.
36. **Cart drawer blocks wait for wave 1.** The review logged SPEC §2.4's 16 drawer blocks as a gap. They are wave-1 scope (DESIGN-money-path §G) and still need the static-section-blocks verification (entry 4); the theme settings that already promised drawer behaviour (note, discount field, vendor, savings line) now work in both the drawer and the cart page.
37. **Discount field is enhanced-only.** Without JavaScript the field is hidden: a blank `discount` field posted with every cart update could clear codes already applied, and Shopify's checkout has its own discount field. With JavaScript, codes are applied through `cart/update.js`, applied codes are listed with remove buttons, and a code Shopify reports as not applicable shows `anvil.cart.code_invalid` instead of a success message.
38. **Provenance record.** The wave-0 cluster briefs were not archived verbatim when they ran and cannot be reconstructed word for word; this pass archives its own brief (`docs/agent-prompts/2026-10-14-fix-pass.md`), and from wave 1 on `scripts/agent-prompt.py <slug> --archive` runs when a section is dispatched (not ahead of time, because a prompt archived before the section exists would not be the prompt actually used). Section cards were added for the wave-0 `anvil-*` sections (`docs/sections/`); the template-bound `main-*` sections are minimal Shopify page shells documented in STATUS and are exempt from DoD #5.
39. **Transparent header.** "Transparent over the first section on the homepage" overlaps the first section by a height Liquid computes from the padding and the logo size (no script involved, so nothing shifts), switches the text to the chosen scheme's colour and, over a dark scheme, to the light logo. Mega menus are header blocks keyed by a top-level menu item's title.
40. **Main-section heading ids.** Template sections that print their own `<h1>` call that setting `title`; `heading` keeps its chassis meaning (inline_richtext rendered by `anvil-section-head`). The cart drawer's heading is `drawer_title`.
28. **Cart drawer blocks stay on the static section** (DECISIONS 4). Statically rendered sections have long supported editor blocks (stored in `settings_data.json` under `current.sections`); wave 1 builds the 16 drawer blocks there. The live-editor check runs when the dev theme is pushed; the `block_list`-style fallback is only needed if that check fails.
29. **Store domain.** The Voreau store's myshopify domain is `ftsegk-n1.myshopify.com` (`shopify.theme.toml`, HARNESS, ARCHITECTURE).
