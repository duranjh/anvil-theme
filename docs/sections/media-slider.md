# Media slider — `sections/anvil-media-slider.liquid`

_Section card, 2026-10-15. Wave 2. Built from `docs/agent-prompts/media-slider.md` (CONVENTIONS, spec card, chassis API, exemplars)._

## Purpose
A carousel of up to 20 slides. Each slide shows an image, an uploaded video or a YouTube/Vimeo link, with an optional caption and link. It fits lifestyle photos, detail shots and short clips on the home page, a landing page or a product template. Spec: `docs/SPEC.md` §4.2 "Image/video slider" (up to 20 slides with media, caption and link; ratio; per view; autoplay; dots/arrows). Design row: `docs/DESIGN-sections.md` §3 `anvil-media-slider` (local `slide` ×20; ratio, per_view, autoplay, dots/arrows, captions; `<anvil-slider>`; video facade).

Phones show 1 or 2 slides, tablets up to 2 and desktop 1 to 5. Part of the next slide shows at the edge whenever more slides are waiting. On phones the row runs to the screen edges, and the first slide keeps the page margin. Without JavaScript it is a scroll-snap row you can swipe.

The full-width hero carousel with content blocks is a separate section, `anvil-hero-slideshow`. This section shows media only.

## Blocks
Local block `slide` ("Slide"). `{{ block.shopify_attributes }}` sits on each `[data-slider-slide]` `<div>`.

| id | type | default | note |
|---|---|---|---|
| `image` | image_picker | — | shown when no video is set, and used as the cover of a YouTube/Vimeo link. Its `info` asks for photos the merchant has the right to use |
| `alt` | text | — | alt text override for the image, the name of an uploaded video's figure when there is no caption, and the facade's name when there is no caption. Blank uses the file's own alt text |
| `video` | video | — | uploaded under Content > Files. Wins over the link and the image. Its `info` asks for products shown as they really are and for a note in the caption when a creator was paid or got the product free |
| `video_url` | video_url (YouTube, Vimeo) | — | used when no video is uploaded. Click-to-load facade, never autoplayed |
| `caption` | text | "Example caption — say what this slide shows" | the `<figcaption>`. Its `info` asks for a truthful description |
| `button_link` | url | — | image slides become one link. Video slides get a text link under the player |
| `button_label` | text | — | visible text link under the slide ("Shop the look"), with an arrow icon. Shown only when a link is set (`visible_if`) |

The preset "Media slider" ships the heading "Example heading — see it **up close**" and five slides whose captions start with "Example caption —". They have no media, so they show the `lifestyle-1`, `lifestyle-2`, `image`, `product-1` and `product-2` placeholders.

## Markup and behaviour
- **Structure:** `anvil-section-head` (only when there are slides, or in the editor), then `<anvil-slider class="av-media-slider …" role="region" aria-label="…">` with `<div class="av-media-slider__track" data-slider-track>`. Each slide holds a `<figure class="av-media-slider__figure">` with the `anvil-media` box (`.av-media-slider__media`) and an optional `<figcaption class="av-media-slider__cap">`. The empty `.av-slider__dots` row follows the track when dots are on. The section loads `anvil-slider.css` and `anvil-slider.js`. It has no JavaScript or asset files of its own.
- **Layout without a shift:** Liquid writes `--av-slider-per-view`, `--av-slider-per-view-desktop`, `--av-slider-gap`, `--av-media-slider-cols-t` and `--av-media-slider-peek` inline. The section CSS sets the component's `--n` at 750 px (tablet count) and again at 990 px (desktop count), as `anvil-testimonials` and `anvil-collection-list` do. The `peek` attribute is left out on purpose, so the script never writes its own inline peek. The section sets `--av-slider-peek` per breakpoint, but only when the row scrolls at that width (`--scroll-m`, `--scroll-t` and `--scroll-d` classes, computed in Liquid from the slide count). A row that fits keeps full-width slides with no empty strip.
- **Phones:** the track bleeds into the page gutter (negative inline margin, the same padding and `scroll-padding`), so peeking slides reach the screen edge while the first slide keeps the page margin. From 750 px the track bleeds only `--av-space-2` (8 px) into the gutter, the same way.
- **Focus ring room:** the track scrolls (`overflow-x: auto` forces `overflow-y` to hidden), so a linked slide's 2 px ring with its 3 px offset would be clipped. The track carries `padding-block: var(--av-space-2)`, taken back by `margin-block: calc(-1 * var(--av-space-2))`, plus the inline padding above. Slide widths do not change (percentage `flex-basis` resolves against the content box), and the negative top margin collapses through `<anvil-slider>`, so the arrows stay centred on the slides. Checked in headless Chrome at 500, 800 and 1280 px: the ring shows on all four sides and the page gains no horizontal scroll.
- **Shapes:** `anvil-media` has no 9:16 box, so `.av-media-slider--r9-16 .av-media-slider__media` sets `aspect-ratio: 9 / 16`. The snippet then gets `adapt`, which still reserves a box from the media's own ratio if that rule is missing. `adapt` slides keep their own shapes and line up at the top.
- **Media sources:** `anvil-media` decides. An uploaded video renders with `video_tag` (controls on, `playsinline`, poster at the last `widths` value). The section passes video slides short poster widths (750 px, 900 px at 2 per view, 1100 px at 1 per view) instead of the image widths, because the poster is one non-responsive file the browser fetches at page load. A lazy video slide's `preload="metadata"` is rewritten to `preload="none"`, so it fetches no metadata until it plays. A YouTube/Vimeo link renders the click-to-load facade (`youtube-nocookie` / Vimeo `dnt=1`, nothing loads before the tap). An image renders with `image_tag`. An empty slide shows a placeholder illustration.
- **Names:** the facade's play link is renamed from "Play video" to `anvil.media.play_title` ("Play video: <caption or alt>"), so several videos in one row have distinct names. The player iframe gets the same title through `alt`. This works by replacing the snippet's exact hidden span, the same way `anvil-video` does; if the snippet's markup changes, the generic label stays. An uploaded video without a caption names its `<figure>` with `aria-label` (the typed alt, else the video's own alt).
- **Links:** an image slide (or an untouched placeholder slide) with a link is one `<a class="av-media-slider__link">` around the figure and the optional label. When the caption or the label names the link, the image inside gets `alt=""` (CONVENTIONS §5), so screen readers hear the name once. `anvil-media` treats `alt: ''` as blank, so the section reads the alt value back from the snippet's output and empties it (`replace_first`, the same kind of rewrite as the play label). When only the alt names the link, the image keeps it. When all three are blank, a visually hidden `anvil.a11y.learn_more` ("Learn more") names it. A video slide is never wrapped, because a link may not contain the player's controls or the facade's play link. It gets `<a class="av-media-slider__cta">` under the media, with the label or "Learn more".
- **Captions:** `below` puts the caption under the media. `overlay` draws it on the media in a box using the section's own `--av-bg` / `--av-fg`, so contrast follows the colour scheme and no colour is hard-coded. The box sits at the bottom of image slides. Video slides keep the caption under the player even in overlay mode, because a box on top would cover iOS Safari's inline controls (fullscreen, volume) and a loaded YouTube/Vimeo title bar. Alignment follows `caption_align`.
- **Auto-advance:** `<anvil-slider autoplay="N">` pauses on hover, focus within, a hidden tab, off-screen and while a block is selected. It starts paused under reduced motion or `html[data-animations="off"]`, and always shows a pause/play button. **The section forces it off while any slide holds an uploaded video or a YouTube/Vimeo link**, so videos never slide away on their own. Only auto-advance is blocked: arrows, dots, swipes and the arrow keys still move the row, and a video with sound (or a loaded YouTube/Vimeo iframe) keeps playing off-screen, since nothing pauses it on `anvil:slider:change` yet (see Open questions). The editor shows `anvil.editor.slider_autoplay_video` under the slider when that happens. Room for the pause button is reserved beside the dots (44 px row, 52 px side padding), or below the slides when dots are off (56 px, `--room-m/t/d`, only at widths where the row scrolls). The button sits at the bottom of the element (`inset-block-end: 0`).
- **Muted video play:** with `video_autoplay`, uploaded videos get `anvil-media`'s `autoplay` (`data-anvil-autoplay`, muted, loop, controls kept). `anvil-core.js` plays a video only while at least 25 % of it is in view and motion is allowed. A video swiped out of the row leaves the view, so it pauses. It also restarts every time it comes back into view, even after the shopper paused it, because `anvil-core.js` does not remember a manual pause yet (see Open questions). YouTube/Vimeo never autoplay.
- **Loading:** media is lazy, except in the first two sections (or when `section.index` is nil), where the slides a phone shows (`per_view_mobile`) load eagerly. Desktop slides past that count are in view and load lazily right after layout, so phones keep their bandwidth for the LCP image. The first slide of the first section gets `fetchpriority: high` and a preload when it is an image. `sizes` comes from the slide counts and `settings.page_width` / `narrow_width`, as in the image gallery; the cap clause starts at `max(cap, 990)` px, so a narrow cap below 990 px never shadows the tablet and phone clauses. `widths` go up to 2200 px when one slide fills the desktop row, otherwise up to 1100 px (video posters: see Media sources).
- **Hover:** a linked image zooms to 1.03 on devices that hover, only with motion allowed and Theme settings > Animations on (`--motion` class). The label turns the accent colour on hover.
- **Keyboard and screen readers:** `role="region"` is written in Liquid next to `aria-label`, so the label is valid without JavaScript (the component keeps an existing role). The rest comes from `<anvil-slider>`: `aria-roledescription="carousel"`, named after the heading (else `anvil.media_slider.label`), slides `role=group` "N of M", ArrowLeft/ArrowRight, a named dots group, and a polite live region (off while auto-rotating). No slide roles are written in Liquid. Captions are not headings, so there is no `<h3>` and no hidden `<h2>`.
- **Empty section:** with zero blocks the shopper sees no heading and no slider (the head renders only when there are slides or in the editor), and the editor shows `anvil.editor.empty_section`.
- **Editor:** `shopify:block:select` scrolls to the slide and pauses auto-advance (component). `shopify:section:load` re-creates the element.
- **CSS:** the `{% stylesheet %}` body is 4,536 bytes raw, 1,377 B gzipped (limit 6,144 raw). Every selector starts with `.av-media-slider`. Media, button and utility styles come from `anvil-base.css`, the carousel controls from `anvil-slider.css` (4,066 B raw / 1,311 B gz). The section adds no JavaScript. `anvil-slider.js` is 14,535 B raw / 4,545 B gz (shared budget 5,120).
- **Lines:** 604, against an estimate of 260. Most of the difference is the schema (about 255 lines), the sizing logic and the output rewrites.

## Honesty notes
- No autoplay with sound. Auto-advance never runs while a video is in the row, and it always has a pause button. The card and the editor note claim only that videos never slide away on their own, not that a playing video stays in view. Muted video play is off by default, keeps controls visible and never runs under reduced motion. YouTube/Vimeo load only on a tap.
- The caption `info` asks merchants to describe what is really shown, and to call something a customer photo or a real result only when it is one. The video `info` asks for products shown as they really are and a disclosure when a creator was paid or got the product free. The image `info` asks for photos the merchant has the right to use.
- Defaults read as examples ("Example heading — …", "Example caption — …") and the preset slides are placeholders, so an unedited store shows nothing that could pass for a real photo or claim.
- The section has no price, stock, rating or badge field.

## Contract assumptions
- `anvil-media` behaves as documented for `image`, `video`, `video_url`, `ratio`, `fit`, `widths`, `sizes`, `loading`, `priority`, `alt`, `placeholder`, `autoplay` and `class`. It prints the facade's play label as `<span class="av-visually-hidden">{{ 'anvil.media.play' | t }}</span>`, which this section replaces with a named label. It writes one ` alt="…"` per image slide (emptied on named links) and ` preload="metadata"` on `video_tag` (rewritten to `none` on lazy video slides). If that markup changes, each rewrite finds nothing and the snippet's own output stays.
- `<anvil-slider>` reads `--n` as its per-view variable (testimonials and collection list rely on it too). It leaves `--av-slider-peek` alone when no `peek` attribute is present, and positions `.av-slider__pause` absolutely inside the element.
- Settings that have never been set (`video`, `video_url`) are blank. The section checks them with `!= blank` in a loop, not with `compact`, so a cleared link does not count as a video.

## Locale keys needed (integrator)
- `anvil.media_slider.label` = "Image and video slider" (the carousel's name when the heading is blank)
- `anvil.media.play_title` = "Play video: {{ title }}" (named facade play link)
- `anvil.a11y.learn_more` = "Learn more" (text link under a video slide with no label; hidden name of an image link with no caption, label or alt)
- `anvil.editor.slider_autoplay_video` = "Auto-advance is off because a slide holds a video, so videos never slide away on their own. Shoppers never see this note."

Existing keys used: `anvil.media.play` (to find the generic label) and `anvil.editor.empty_section`, plus the `anvil.media.*` and `anvil.a11y.*` strings used inside `anvil-media` and `anvil-slider`.

## Open questions
- **Arrow keys on a focused `<video>` (integrator, `assets/anvil-slider.js:348`).** The keydown handler skips form fields only, so ArrowLeft/ArrowRight on a focused native player change the slide (and `preventDefault` stops seeking) instead of seeking. Change the guard to `if (e.target.closest('input, textarea, select, [contenteditable], video, audio')) return;`. This section ships the combination; the card no longer claims a playing video stays in view.
- **Pause videos that leave the view (integrator, `assets/anvil-slider.js`).** Only auto-advance is blocked. Arrows, dots and swipes move a playing video (with sound) or a loaded YouTube/Vimeo iframe out of view, and it keeps playing. On `anvil:slider:change`, pausing `video` elements in slides scrolled out of view would fix it for every slider without new section JS.
- **Respect a manual pause (integrator, `assets/anvil-core.js` `autoplay()`).** The IntersectionObserver calls `play()` on every re-entry, so a looping video the shopper paused restarts when swiped back. Proposed: on a `pause` event the observer did not trigger, set `target.dataset.anvilUserPaused = ''` and skip `play()` while it is set; clear it on a `play` the shopper starts. The `video_autoplay` info no longer says "always" until then.
- **Video loading in `anvil-media` (integrator).** When `loading != 'eager'`, emit `preload: 'none'` on `video_tag` (this section rewrites it in the meantime), and ideally keep the poster in a data attribute that `anvil-core.js` sets on approach, so posters below the fold are not fetched at load. This section caps the poster width (750 / 900 / 1100 px) in the meantime.
- **A `decorative` switch in `anvil-media` (integrator).** CONVENTIONS §5 says to pass `alt: ''` inside a named link, but the snippet treats `''` as blank and falls back to `image.alt`. This section now empties the alt by rewriting the snippet's output. A `decorative` (or `alt_none`) parameter that writes `alt=""` would let the section drop that rewrite: pass it when `link_named` is true.
- **9:16 in `anvil-media`.** This is the third section (after `anvil-video` and `anvil-product-videos`) that overrides `aspect-ratio` for 9:16. A `9:16` ratio in the snippet, plus `.av-media--9-16` in base CSS, would remove all three overrides.
- **Arrow position.** The component centres the arrows on the track height, which includes captions below the media, so with "Under the media" captions the arrows sit a little below the media's centre. It is fine visually, and changing it belongs to the component.
- **Gate script.** `npm run gate -- media-slider` was not run: its paths gate runs `git status`, which builders in this wave may not run. G1 (theme check: only the four missing locale keys above) and G2 (cleanroom-lint, asset-audit, chassis-lint, check-limits: clean for this section) were run one by one. The layout and focus ring were checked in headless Chrome against a static mock of the rendered markup. It has not been rendered on the dev theme (375 × 812 and 1280 × 800, reduced motion, axe) yet.

## Integration pass (2026-10-15)
- The output rewrites are gone: `anvil-media` takes `play_label` ("Play video: <caption>" from `anvil.media.play_title`), `decorative` (image inside a named link) and writes `preload="none"` for lazy videos itself. The fallback link name is `anvil.a11y.learn_more`.
- `anvil-slider.js` now skips arrow keys on native video and audio and pauses a playing video with sound that a slide change moved out of view; `anvil-core.js` remembers a shopper's pause on muted autoplay video.
